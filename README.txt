# BARBER BROTHERS — Free Website

This is a static, mobile-friendly website for Barber Brothers.

## Included
- Responsive red/white barber-shop design
- WhatsApp appointment booking with pre-filled permanent message
- Call button
- Google Maps / directions
- Google Reviews link
- Instagram link
- Services and prices
- Combo offers
- Events & offers placeholder
- Gallery section
- SEO title and description
- Mobile sticky booking button

## Publish free with GitHub Pages
1. Create a free GitHub account.
2. Create a new public repository, for example `barber-brothers`.
3. Upload `index.html`, `style.css`, and `logo.jpg`.
4. Open repository Settings → Pages.
5. Select Deploy from branch → main → /root.
6. Save. GitHub will provide your free website address.
